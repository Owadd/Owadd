### About Me

> *"I question answers, question questions, and let data lead me to hidden truths. I build systems that turn complexity into clarity."*

- **Vision AI & Document Forensics:** Building open-weight multimodal pipelines (`Qwen2.5-VL-7B` in 4-bit `NF4`) that run on free cloud GPUs to audit handwritten records at zero API cost.
- **Machine Learning & Data Engineering:** Designing end-to-end data workflows, predictive risk/churn models, and executive intelligence dashboards.
- **Currently Working On:**
  - Extending [**EC8A-Sentinel**](https://github.com/Owadd/EC8A-Sentinel) with multi-model agreement checks and word-to-digit ballot reconciliation
  - Publishing interactive visual benchmarks and dashboards on [**owadd.github.io**](https://github.com/Owadd/owadd.github.io)
  - Scaling reproducible financial and market analytics pipelines in Python & SQL
